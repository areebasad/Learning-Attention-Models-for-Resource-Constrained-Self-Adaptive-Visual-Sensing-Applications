# Learning-Attention-Models-for-Resource-Constrained-Self-Adaptive-Visual-Sensing-Applications


The repository contains a codebase for learning attention models. 
The experiments and their results are listed in the paper "Learning-Attention-Models-for-Resource-Constrained-Self-Adaptive-Visual-Sensing-Applications"
